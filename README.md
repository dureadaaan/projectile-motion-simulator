# 🚀 Projectile Motion Simulation  

A Java-based simulator of projectile motion built with **OOP principles** and **Swing GUI**. It supports both default and custom inputs for angle, velocity, gravity, resistance, and height, then calculates range, time of flight, and trajectory, with real-time animation.  

---

## ✨ Features  
- 🎛 **User-friendly GUI** built with Swing  
- ⚙️ **Custom & Default Simulation Modes**  
- 📏 Calculates **Range, Time of Flight, Peak Time**  
- 📉 Visualizes **Trajectory Path** with animation  
- 🧑‍💻 Implements **Abstraction, Inheritance, Encapsulation, Polymorphism**  

---

## 🛠 Tech Stack  
- **Language:** Java  
- **GUI Framework:** Swing, AWT  
- **Concepts:** OOP, Physics Simulation  

---
